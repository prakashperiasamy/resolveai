# Repository distribution

Repository: `prakashperiasamy/resolveai`.

Public publication was approved by Prakash Periasamy on October 11, 2026. This repository distributes editable source, synthetic fixtures, offline demonstrations, and executive materials. The verification workflow runs tests and builds; it does not deploy a website.

## Maintaining the portfolio

Run `npm ci`, `npm test`, and `npm run build` before publishing changes. Update the source and verification results together. Rebuild the standalone demo when dashboard behavior changes; the HTML files are retained distribution artifacts, not the editable source of truth.

GitHub Pages is not enabled by this publication. Enabling a hosted demo is a separate optional step.
